# 流体模拟备忘（Build 26）

> 主题：水/岩浆流动模拟（M1 可流动 + M3 打磨 + M2 部分水位）。核心文件 `src/core/FluidSim.js`。

## B26 设计决策（防回退）

- **流动体 = 独立方块 id**（`water_flow_1..7` / `lava_flow_1..3`，等级 1 最强 → N 最弱；源 `water`/`lava` 等级恒 0）。
  存档 Uint8Array、联机协议、光照（light=15）、modifiedBlocks 全部复用方块 id 通道自动兼容，零迁移。
  **勿改成"元数据/扩展格"方案**——会破坏以上全部免费兼容。
- **判定按 `def.fluidType` 不按 name**：流动等级方块 name 带后缀，`name === 'water'` 精确匹配会漏。
  fluidType 经 `BlockRegistry.register` 的**字段白名单**透传——**新增 def 字段必须同步加进白名单**（B26 踩坑：fluidType 首次注册被白名单丢弃，游泳/渲染判定全失效，node 测试因不依赖该字段而漏检，靠 agent-browser 实机才发现）。
- **扰动触发，非全量模拟**：只在流体格或其 6 邻被 setBlock 改动时入队（`World.setBlock` 收口调 `fluidSim.onBlockChanged`）。
  地形生成的海洋/岩浆海是静态源，永不自发流动。区块重载扫描（`_finalizeChunk`）把 modifiedBlocks 里的流动等级格再入队（防存档重载后瀑布断流）。
- **供给重算规则**（`_simulate`）：
  - 期望等级 e = 上方同型流体 ? max(1, 上方等级)（**垂直零衰减**，瀑布柱内恒强）: min(水平 4 邻等级)+1；
  - e < 当前 → **直接升级**；e > 当前 → **逐级 +1 消退**（超上限变空气，切断源呈波状回退）；
  - e == 当前 → 扩散。缺 e > level 分支会导致"流动体互相供给永不消退"（B26 踩过）。
- **扩散**：优先向下（下落满强 = 等级 1），有下落出口不水平扩散（防瀑布柱沿途横散）；下方已是同型流体直接 return（通道延续由下方格自身重算收敛，防同强度重写死循环）。
- **相遇固化在扩散目标位判定**（原版语义"流体流向异型流体"）：水→岩浆源=黑曜石、水→流动岩浆=圆石、岩浆→水=石头。
  **勿做"水格 tick 主动扫 6 邻岩浆"**——会让水 tick 永远先手灭掉岩浆，规则③（岩浆流向水）在确定性交替步进下永不可达。
- **步进节奏**：水 250ms/步、岩浆 500ms/步，每步队列预算 256 格（防流动风暴）。
- **联机**：host/单机权威模拟（客户端 `fluidSim.muted=true` 不跑 step 也不积累队列，靠 host 广播收敛，与作物生长同款门控）。
  模拟内写入统一走 `FluidSim._apply`（`writing` 标志窗口）→ NetworkManager 据此分流：流体改动进 250ms 窗口**覆盖式合并**批量（`block_set_batch`），玩家操作保持单条即时。
  服务器 `onBlockSetBatch` 逐格落账本 + 一条 `block_change_batch` 广播；限速按消息计（1 条）不按格数（`ratelimit.tierOf`）——否则流动风暴撞 block:900/分钟 限速丢包。

## M2 部分水位（ChunkMesh）

- 水面高度：上方同型流体（下落柱）→ 满高 1.0；否则 `(8 - level) / 9`（源 8/9 ≈ 旧版 -0.1 假水位，海面观感几乎不变）。
- 顶面贪心合并 `_mergeWaterTops` 按 **(y, 高度) 分层**（waterTops stride 4：x,y,z,h），仅同高合并——海洋源同层合并不受影响。
- 剔除规则：同型流体**顶/底面**恒剔（垂直重叠）；**侧面仅同高剔**（不同高画台阶侧壁）。
- 岩浆走 solid 管线（不透明发光），顶面/侧面同样按 fluidH 降高；light mesh 顶点 `y + fluidH + yOff`。
- 几何断言注意 **Float32 精度**：顶点 y 经 Float32Array 有 ~3e-6 误差，断言容差用 1e-4（曾用 1e-6 误判失败）。
