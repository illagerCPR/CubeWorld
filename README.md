# Project-MC

网页版 3D Minecraft（Web 版我的世界），基于 **Vite 5 + Three.js 0.160** 的纯前端体素游戏，支持**单机存档**与**局域网联机**。

- 程序化生成无限世界（确定性种子，联机时各端生成一致地形）
- 创造 / 生存 / 旁观三种模式
- 方块挖掘、放置、合成、背包、快捷栏（**60+ 方块材质按原版重绘**：砖缝/木板拼条/圆石砌块/年轮/矿石晶簇）
- 日夜循环、怪物系统（单机：4 种怪 **box-parts 立体建模 + 法线光照 + 原版风格皮肤（脸朝移动方向、僵尸/骷髅手臂前伸、苦力怕经典脸、蜘蛛红眼）**、AI、受击反馈/血条、死亡动画）、红石电路（拉杆/活塞/TNT/红石灯等）
- 多槽位本地存档（localStorage）
- **局域网联机**：Node 房间服务器 + 各端同种子生成世界，方块/玩家/聊天实时同步

## 快速开始

### 环境要求

- Node.js 18+（开发用 24 验证）
- npm

### 安装依赖

```bash
npm install            # 前端依赖（three / vite）
npm install --prefix server ws   # 联机服务器依赖
```

### 启动开发服务器

```bash
.\start.cmd start      # 启动 Vite dev server → http://127.0.0.1:5173
.\start.cmd stop       # 停止
.\start.cmd restart    # 重启
.\start.cmd status     # 查看状态
```

浏览器打开 `http://127.0.0.1:5173` 即可开始单机游戏。

### 生产构建

```bash
npm run build          # 产物输出到 dist/
npm run preview        # 预览构建产物
```

## 局域网联机

> 阶段 7：方块共建/破坏、玩家可见与移动、互殴、死亡重生、昼夜同步、聊天、**掉落物与拾取同步**、**断线自动重连**、**怪物同步（事件同步：host 生成 + 受击/死亡广播 + 位置校正）**、**红石状态同步**、**多房间（同名房间共享世界）**、**世界落盘（服务器重启不丢世界）**、**玩家名着色**、**远端玩家插值优化（行走动画/头部俯仰/瞬移快照）**、**观战（死亡后旁观其他玩家）**、**服务器管理面板（房间/玩家/配置/世界管理）**、**世界内换房/重建世界（`/room` `/rebuild`，无需回主菜单）**、**时间戳对齐插值（远端更平滑）**、**管理面板鉴权（可选口令）**、**手持物品外观同步（远端手部可见手持物）**、**玩家死亡掉落物（死亡散落背包、可拾取）**、**观战视角平滑**、**鉴权增强（口令过期 + 操作日志）**、**插值延迟自适应（按网络抖动自动调节）**、**4 种怪物建模优化（法线光照 + 方形皮肤 + 细节纹理 + 模型细化）**。联机模式**不写本地存档**。
>
> 渲染修复（阶段 8）：怪物**脸朝移动方向**（修复脸贴头顶/蜘蛛头拖尾）、皮肤 **atlas 扩为 96×64 六面独立贴图**并按原版重画、侧面贴图**去镜像**、**天空盒跟随玩家**（修复远离原点后天空纯黑）。
>
> 材质重绘（阶段 9）：全部方块 SVG 按原版配色与结构化像素画重画（圆石砌块/石砖/红砖缝/木板拼条/年轮/矿石晶簇等）；修复含发光方块区块重建导致的画面冻结。
>
> 联机小提示：生存模式下挖矿会掉落**物理掉落物**（谁都能拾取，掉落物 5 分钟消失）；**玩家死亡会把整个背包散落在原地**（其他玩家也能拾取），重生后重新获得生存初始物品；断线后会自动重连回原房间，位置与背包不丢；夜晚会刷怪（由开房者决定生成，所有人都能打）；世界按**房间名**保存到服务器磁盘（`server/world/`），重启服务器后进同名房间即可接着玩；死亡后点「观战其他玩家」可旁观房间内玩家（F5 切换目标，R 重生）；游戏内按 **T** 输入 `/room <房间名>` 直接换房、`/rebuild`（房主）重建当前世界。

### 1. 启动房间服务器

```bash
.\start.cmd server     # 启动联机服务器 → ws://0.0.0.0:3001/ws
.\start.cmd server-stop  # 停止
```

> Windows 首次监听可能弹出防火墙授权，需放行 TCP 3001。

### 2. 开房 / 加入

1. 开房者打开 `http://<开房机IP>:5173`，主菜单 →「局域网联机」→ 填**昵称**与**房间名** → **创建房间**（决定该房间世界种子）。
2. 其它玩家在局域网内访问 `http://<开房机IP>:5173`，填昵称、服务器地址 `ws://<开房机IP>:3001/ws` 与**相同的房间名** → **加入房间**。
3. 进入同一世界后即可共建方块、互相可见、按 **T** 聊天。

> 联机世界由开房者种子决定；新加入者会自动收到已存在的方块改动（账本回放），所见即世界现状。
>
> **多房间**：房间名相同的玩家进入同一世界；房间名不同则完全隔离。服务器会把每个房间的世界保存到 `server/world/`，**重启服务器后进同名房间自动恢复原世界**；换/新建世界只需换一个房间名。
>
> 游戏内命令：**T** 打开聊天后输入 `/rooms` 列出房间、`/seed` 查看当前世界种子、`/room <房间名>` 世界内直接换房（保持连接）、`/rebuild`（房主）重建当前世界、`/help` 查看全部命令。

### 3. 服务器管理面板（阶段 4+5+6）

服务器还内置一个 **Web 管理面板**：开房机浏览器打开 `http://127.0.0.1:3001/`（其它电脑可用 `http://<服务器IP>:3001/`）即可：

- **状态总览**：运行时长、房间列表、每房间在线玩家（模式/生命/位置）、方块改动数、掉落物数。
- **配置管理**：掉落物过期毫秒（`dropTtlMs`）、心跳间隔毫秒（`heartbeatMs`）、每房间最大玩家数（`maxPlayersPerRoom`）、管理口令（`adminToken`）、口令过期分钟（`adminTokenExpires`），修改即生效并写入 `server/config.json`（重启保留）。
- **广播**：向所有房间发送系统公告。
- **玩家管理**：按玩家踢出（被踢客户端停止自动重连）。
- **世界管理**：清空某房间掉落物；删除某房间（踢出所有玩家 + 移除磁盘存档 = 重置该世界）。
- **操作日志（阶段 6）**：记录最近 200 条管理操作（配置/广播/踢人/清掉落物/删房/未授权访问），面板实时展示。
- **鉴权（阶段 5+6）**：在面板「配置管理」设置**管理口令**（`adminToken`，留空=关闭）后，所有 `/api/*` 接口与面板都要求输入口令（浏览器自动记住，可选手机会话 1h/24h/7天）；未授权请求返回 401，接口不会回显口令明文。可再设**口令过期分钟**（`adminTokenExpires`）让口令到期后自动失效（到期后仅允许通过面板续期/关闭鉴权，避免永久锁死）。

### 4. 服务器协议回归测试

```bash
node server/index.mjs      # 先启动服务器（建议先清空 server/world/ 与 server/config.json 保证干净状态）
node server/test-mp.mjs    # 跑 34 项协议断言（方块/玩家/掉落物/怪物/红石/离开广播/多房间隔离/命令）
node server/test-store.mjs # 世界落盘往返测试（15 项，无需服务器）
node server/test-admin.mjs # 管理面板 API 回归（26 项：人数上限/踢出/清掉落物/删房/配置/广播/鉴权）
node server/test-stage5.mjs # 阶段 5 回归（16 项：世界内换房/重建世界/时间戳）
node server/test-stage6.mjs # 阶段 6 回归（20 项：手持物品/死亡掉落物/鉴权过期与操作日志）
```

> 注意：回归测试对**同一台持续运行的服务器**非幂等（测试房间与世界存档会累积、鉴权用例会改动口令）。重复跑批前请重启服务器（或清空 `server/world/` 与 `server/config.json`）。

## 架构要点

- **确定性世界生成**：地形由 `TerrainGenerator(seed)` 用 SimplexNoise + LCG 伪随机生成，全流程无 `Math.random`。这是联机"各端自行生成相同地形、只同步修改增量"的基础。
- **单一方块写入入口**：`World.setBlock` 是唯一方块修改入口，联机时统一经它上报（挖掘/放置/TNT 爆炸/活塞全覆盖），并带 `_applyingRemote` 防回环标志。
- **存档**：localStorage 多槽位（`project-mc-save-N`），存 `seed + modifiedBlocks 增量 + 玩家状态 + 红石 + 时间`。
- **联机模型**：轻量主机 + 各端自跑。Node 服务器只做房间管理、方块账本（last-write-wins 仲裁）、玩家中继、昼夜权威；客户端各自生成世界、自跑物理，只同步外部可见状态。

## 已知限制（联机阶段 8）

- 怪物同步采用**事件同步**（host 权威生成 + 受击/死亡广播 + 受击位置校正）：同一只怪在各端 AI 独立跑，位置可能有轻微漂移（局域网信任场景可接受）；非攻击致死（白天燃烧、掉虚空）各端可能各自产生掉落物。
- 红石各端独立收敛 + lever/button 状态低频广播，高频红石（快速闪烁）仍可能有轻微 tick 漂移。
- 方块冲突采用 last-write-wins（局域网信任场景可接受）。
- 背包/物品栏**不做全量同步**（各端自管自身背包），仅同步手持槽位与生命/饥饿；拾取掉落物由拾取端本地入包；死亡掉落物由死亡端上报背包生成（先到先得拾取）。
- 掉落后若背包恰好满格，拾取会只取部分（联机下余量按"整个掉落物消失"处理，极少数情况）。
- 世界内换房/重建：`/room <房间名>` 换房、`/rebuild`（房主）重建当前世界——换房/重建会**重启本地世界**（类似重新进房，背包物品按生存初始重置；各房间背包互不相通）。
- 世界落盘为**服务器内存账本 + 磁盘快照**：方块/掉落物/时间会持久化，各端本地地形仍由种子确定性生成（重建自然地形），落盘不含玩家背包/位置。
- 断线自动重连依赖服务器仍在运行；服务器重启后需按**相同房间名**重新加入以恢复世界。
- 观战为**死亡后旁观**：第一人称跟随被观战玩家（F5 切换目标，R 重生），无目标时自由飞行；观战状态下不广播自己的位置（其他玩家看不到观战者）。
- 手持物品外观为**右手 billboard sprite**（跟随手臂摆动），尚未做 3D 化渲染；仅同步选中槽位物品，未同步整条快捷栏。
- 管理面板**默认无鉴权**（局域网信任环境）；如需限制，可在面板「配置管理」设置**管理口令**（`adminToken`），开启后所有 API 须带口令；可设**过期分钟**让口令到期失效（到期后仅能通过面板续期/关闭，或编辑 `server/config.json` 后重启服务器）。
